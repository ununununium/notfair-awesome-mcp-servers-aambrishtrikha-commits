# Contributing

## Adding a Server

1. Fork this repo
2. Add the server to the correct category in README.md
3. Format: `[Name](URL) — Brief one-sentence description.`
4. Alphabetical order within category
5. Submit a PR

## Requirements
- Server must be publicly accessible or open source
- Must be actively maintained (updated within last 6 months)
- Must follow MCP specification
- Brief, accurate description

## Creating a New Category
If your server doesn't fit existing categories, propose a new one in your PR description.
